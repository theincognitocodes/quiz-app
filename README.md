# 🧠 Quiz Time - Quiz App

A simple and interactive **Quiz Application** built using **HTML, CSS, and JavaScript**.

Test your knowledge with multiple-choice questions, get instant feedback, track your score, and see your final result at the end of the quiz.

## 🚀 Live Demo

👉 [View Quiz App](https://jovial-moxie-c09b1a.netlify.app)

## 📌 Features

* 🎯 Start and restart the quiz
* ❓ Multiple-choice questions
* ✅ Highlights the correct answer
* ❌ Shows incorrect answers
* 📊 Real-time score tracking
* 📈 Question progress bar
* 🏆 Final score and result message
* 📱 Responsive design for mobile and desktop
* ⚡ Fast and lightweight
* 🌐 Deployed using Netlify

## 🛠️ Technologies Used

* **HTML5** – Structure of the application
* **CSS3** – Styling and responsive design
* **JavaScript** – Quiz logic and DOM manipulation
* **Netlify** – Deployment

## 🎮 How It Works

1. Click **Start Quiz**.
2. Read the question and select an answer.
3. The correct answer is highlighted.
4. Your score is updated automatically.
5. The progress bar shows your quiz progress.
6. After answering all questions, your final score is displayed.
7. Click **Restart Quiz** to play again.
